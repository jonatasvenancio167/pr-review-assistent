# Contexto e escopo

Sistema inteligente de revisão de código-fonte que utiliza Python, arquitetura baseada em Service Objects, RAG e Large Language Models (LLMs) para identificar possíveis problemas técnicos em alterações de código e fornecer recomendações fundamentadas em uma base de conhecimento.

| Entrada | Git Diff |

| Persistência | PostgreSQL + pgvector |
| Objetivo | Aprendizado técnico |
