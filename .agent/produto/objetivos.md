# Objetivos do projeto

[Voltar ao índice](../../AGENTS.md)

## Objetivo geral

Desenvolver uma aplicação em Python capaz de realizar revisões automatizadas de alterações de código-fonte, utilizando técnicas de RAG e LLM, com arquitetura modular baseada em Service Objects.

## Objetivos específicos

1. Desenvolver uma API REST para receber diffs.
2. Implementar o processamento e a interpretação de Git Diff.
3. Criar uma base de conhecimento com padrões e boas práticas de programação.
4. Implementar pipeline de ingestão, chunking e embeddings.
5. Implementar recuperação semântica utilizando PostgreSQL e pgvector.
6. Integrar um modelo de linguagem por API.
7. Desenvolver um mecanismo de validação dos achados.
8. Implementar testes unitários, de integração e avaliação de qualidade.
9. Garantir rastreabilidade entre os achados e suas evidências.
10. Manter baixo acoplamento entre domínio, serviços e integrações externas.
