# Estratégia de recuperação

[Voltar ao índice](../../AGENTS.md)

O retrieval deverá considerar:

- Similaridade semântica.
- Linguagem analisada.
- Categoria do problema.
- Relevância do documento.
- Quantidade máxima de fragmentos.
- Limite de contexto do modelo.

Como evolução, podemos utilizar uma abordagem híbrida, combinando busca vetorial com busca textual. Isso pode melhorar a recuperação de termos técnicos, identificadores e nomes de APIs.
