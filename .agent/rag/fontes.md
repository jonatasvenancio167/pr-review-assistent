# Base de conhecimento e fontes

[Voltar ao índice](../../AGENTS.md)

A base de conhecimento será um dos componentes centrais do projeto.

Não queremos armazenar documentos indiscriminadamente. Precisamos de uma base organizada, com informações relevantes para o processo de revisão.



## Fontes iniciais de conhecimento


Minha recomendação é começar com:

| Fonte | Conhecimento |
| --- | --- |
| PEP 8 | Convenções de código Python |
| PEP 257 | Convenções de documentação |
| OWASP | Segurança de aplicações |
| Python Documentation | Recursos e comportamento da linguagem |
| Ruff | Regras de análise estática |
| Documentação SQLAlchemy | Boas práticas de persistência |
| Documentação pytest | Estratégias de testes |

A documentação oficial e as versões de referência deverão ser registradas para evitar recuperar regras desatualizadas.
