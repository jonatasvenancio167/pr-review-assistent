# Critérios de aceite do MVP

[Voltar ao índice](../../AGENTS.md)

O projeto estará funcional quando:

- [ ] Receber um diff Python válido.
- [ ] Identificar corretamente arquivos e linhas modificadas.
- [ ] Diferenciar linhas adicionadas e removidas.
- [ ] Recuperar conhecimento relevante no banco vetorial.
- [ ] Enviar contexto ao LLM.
- [ ] Gerar achados estruturados.
- [ ] Validar evidências e localizações.
- [ ] Classificar os problemas por severidade e categoria.
- [ ] Retornar relatório em JSON.
- [ ] Tratar falhas externas corretamente.
- [ ] Possuir testes automatizados.
- [ ] Possuir avaliação de qualidade do RAG e do LLM.
- [ ] Não executar o código recebido.
