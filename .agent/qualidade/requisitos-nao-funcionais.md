Além das funcionalidades, precisamos estabelecer características de qualidade do sistema.

| ID | Requisito | Descrição |
| --- | --- | --- |
| RNF-01 | Modularidade | Serviços independentes e responsabilidades bem definidas |
| RNF-02 | Testabilidade | Cobertura de testes unitários e integração |
| RNF-03 | Segurança | Não executar código submetido |
| RNF-04 | Observabilidade | Logs estruturados e rastreamento das etapas |
| RNF-05 | Escalabilidade | Possibilidade de evoluir para processamento assíncrono |
| RNF-06 | Manutenibilidade | Baixo acoplamento e alta coesão |
| RNF-07 | Resiliência | Tratamento de indisponibilidade de APIs externas |
| RNF-08 | Rastreabilidade | Relacionar achados, diff e referências |
| RNF-09 | Configurabilidade | Configurações externas ao código |
| RNF-10 | Reprodutibilidade | Avaliações e testes executáveis de maneira consistente |
