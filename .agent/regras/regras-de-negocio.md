# Regras de negócio

[Voltar ao índice](../../AGENTS.md)

As regras abaixo representam o comportamento esperado independentemente da tecnologia utilizada.

| Código | Regra |
| --- | --- |
| RN-01 | Não realizar revisão sem diff válido. |
| RN-02 | O MVP deve analisar alterações Python. |
| RN-03 | Priorizar as linhas adicionadas. |
| RN-04 | Nunca executar o código submetido. |
| RN-05 | Todo achado deve possuir evidência. |
| RN-06 | A evidência deve corresponder ao código recebido. |
| RN-07 | A severidade deve pertencer a uma classificação controlada. |
| RN-08 | O RAG deve recuperar documentos relevantes. |
| RN-09 | Falhas de dependências devem ser explícitas. |
| RN-10 | O sistema não deve corrigir código automaticamente. |
| RN-11 | Os achados devem manter rastreabilidade. |
| RN-12 | Credenciais e informações sensíveis devem ser protegidas. |
| RN-13 | Entradas, contexto e tempo de execução devem possuir limites. |
| RN-14 | A resposta do LLM deve respeitar um contrato estruturado. |
