# Classificação dos achados

[Voltar ao índice](../../AGENTS.md)

| Severidade | Significado |
| --- | --- |
| Critical | Problema potencialmente crítico, com risco muito elevado |
| High | Problema de alto impacto potencial |
| Medium | Problema relevante que deve ser corrigido |
| Low | Melhoria ou problema de baixo impacto |
| Info | Observação técnica sem risco significativo identificado |

A classificação precisa ser acompanhada de critérios objetivos e exemplos no prompt do modelo. Não devemos permitir que a severidade seja atribuída apenas por intuição.
